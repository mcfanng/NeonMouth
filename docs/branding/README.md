# Branding

- **App name:** NeonMouth (decided 2026-09-19). Code, project and namespaces renamed to match.
- **Logo/icon:** `neonmouth-logo-prototype.png` (1024×1024 prototype): a neon face with green eyes and a purple waveform mouth. Used as the app icon foreground (`Resources/AppIcon/appiconfg.png`) on a `#0B0B14` background.
- **Splash screen:** `NeonMouth/Resources/Splash/splash.png` (logo + "NeonMouth" on `#0B0B14`), generated by `make-splash.ps1 -LogoPath neonmouth-logo-prototype.png -Out ../../NeonMouth/Resources/Splash/splash.png`. Content stays inside the central circle because Android 12+ crops the splash icon to a circle.
